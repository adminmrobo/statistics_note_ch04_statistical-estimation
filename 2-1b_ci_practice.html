왜 이 실습인가

1정답을 알고 시험하기

진짜 조사에서는 모평균을 모릅니다. 실습에서는 데이터 전체를 모집단으로 놓아 정답을 알고 신뢰구간 방법을 채점합니다.

2코드 숫자를 직접 확인

파이썬·R로 구한 구간이 실제로 모평균을 담는지, 95%와 99%가 얼마나 다른지 손으로 확인합니다.

3교과서에 잘 안 나오는 함정

모집단(400명)의 큰 부분을 뽑으면 보통 공식이 틀어집니다. 유한 모집단 보정이 왜 필요한지 숫자로 봅니다.

박사

박사의 한 줄: 실습의 핵심은 "구간이 맞았나"가 아니라 "이 방법이 몇 %나 맞나"를 재는 거예요.

데이터에 대해: 실습 파일 두 개 — 중간고사 성적 ch4_scores400.csv(400명)와 유명인 사망 나이 death.csv(21,458명, Kaggle Celebrity Deaths 2006~2016의 나이 열) — 를 페이지 안에 그대로 넣었습니다. 사망 나이에는 0세·125세 같은 원본 그대로의 극단값도 남아 있습니다. 다른 데이터로 해 보려면 아래 ①칸의 "내 CSV 열기"로 파일을 고르면 모든 숫자가 그 데이터로 다시 계산됩니다. 파일은 브라우저 안에서만 읽고 어디에도 보내지 않습니다.

큰 그림 — 세 칸 실습

칸할 일새로 생긴 능력한계 → 다음 칸
①데이터 전체를 모집단으로모평균 μ(정답)와 분포 모양을 안다현실에서는 표본만 본다 → 표본을 뽑자
②표본 하나로 95·99% 구간x̄ ± 임계값·s/√n을 계산하고 μ와 비교한 번 맞았다고 방법이 좋은지는 모른다
③1,000번 반복 채점적중률로 방법을 채점, 유한 모집단 보정현실에선 정답이 없다 → 방법을 믿는 근거를 모의실험으로 쌓는다
1모집단

데이터 전체를 모집단으로 — 정답을 아는 실습장

모델: μ = 데이터 전체 평균연구실: 정답지를 봉인해 둔 시험장

연구실에서는

봉인관이 정답지(모평균)를 봉투에 넣어 두고, 하루는 표본만 보고 구간을 만듭니다. 다 만든 뒤 봉투를 열어 채점합니다.

통계로는

실습에서는 400명 성적(또는 사망 나이 전체)을 모집단으로 정의합니다. 그래서 모평균 μ를 정확히 알고, 표본으로 만든 구간이 μ를 담는지 채점할 수 있습니다.

초파리 연구원

사망 나이는 평균이 중앙값보다 작네. 왼쪽 꼬리가 길다는 뜻이야 — 그래도 구간이 맞을까?

2구간

표본 하나로 95%·99% 구간 — 그리고 봉투 열기

모델: x̄ ± z(α/2)·s/√n연구실: 표본만 보고 답안 쓰기

연구실에서는

하루가 n명을 무작위로 뽑아 평균과 표준편차를 구하고, 95%·99% 구간 두 개를 답안지에 씁니다. 그다음 봉투를 열어 μ가 들어왔는지 봅니다.

통계로는

표본 크기가 30 이상이면 σ 대신 s를 써도 z 구간과 t 구간이 거의 같습니다. 폭은 √n에 반비례하고, 신뢰수준이 높을수록 넓어집니다.

n
임계값
파이썬·R 코드로 같은 계산 하기 
# 파이썬 (pandas, scipy)
import pandas as pd, numpy as np
from scipy import stats
pop = pd.read_csv('ch4_scores400.csv').iloc[:, 0]     # 첫 열이 점수라고 가정
mu  = pop.mean()                                      # 정답(모평균)
smp = pop.sample(100, random_state=1)                 # 비복원 무작위 표본
xb, s, n = smp.mean(), smp.std(ddof=1), len(smp)
for lv in (0.95, 0.99):
    z = stats.norm.ppf(1 - (1 - lv) / 2)
    lo, hi = xb - z * s / np.sqrt(n), xb + z * s / np.sqrt(n)
    print(lv, round(lo, 2), round(hi, 2), lo <= mu <= hi)
# R
pop <- read.csv("ch4_scores400.csv")[[1]]
mu <- mean(pop); set.seed(1); smp <- sample(pop, 100)
for (lv in c(0.95, 0.99)) {
  z <- qnorm(1 - (1 - lv) / 2); m <- z * sd(smp) / sqrt(length(smp))
  cat(lv, mean(smp) - m, mean(smp) + m, (mean(smp) - m <= mu) && (mu <= mean(smp) + m), "\n")
}

풀이 — 숫자 읽기

  1. 표본에서 x̄와 s를 구한다(표본표준편차는 n−1로 나눈다, 2.5에서 이유).
  2. 표준오차 s/√n에 임계값(95%: 1.96, 99%: 2.576)을 곱해 오차한계를 만든다.
  3. 봉투를 열어 μ가 [하한, 상한] 안에 있는지 본다 — 이번 한 번의 결과일 뿐이다.

이 칸의 한계: 한 번 맞았다(또는 틀렸다)고 방법이 좋다(나쁘다)고 말할 수 없습니다 → ③ 반복 채점

3채점

1,000번 반복 채점 — 그리고 유한 모집단 보정

모델: 적중률 = 맞은 구간 / 1,000연구실: 같은 시험을 1,000번 치르기

연구실에서는

같은 방법으로 답안을 1,000장 쓰고 모두 채점합니다. 95% 방법이라면 950장쯤 맞아야 합니다. 그런데 400명 중 200명이나 뽑으면 이상한 일이 생깁니다.

통계로는

모의실험으로 적중률을 재면 방법을 채점할 수 있습니다. 모집단이 작고 비복원추출로 큰 비율을 뽑으면 실제 흔들림이 공식보다 작아, 표준오차에 유한모집단 보정 √((N−n)/(N−1))를 곱해야 합니다.

신뢰수준

데이터 분석으로 치면

회사 고객 5,000명 중 3,000명에게 설문을 돌렸다면 표본이 모집단의 60%입니다. 이때 보통 공식의 오차한계는 실제보다 크게 나옵니다(보정 계수 √(2000/4999) ≈ 0.63).

비유의 한계: 응답한 3,000명이 무작위가 아니라면(응답 편향) 보정을 해도 결과가 치우칩니다.

현장에 옮기면

현실의 조사에는 봉투(정답)가 없습니다. 그래서 방법을 믿는 근거는 오늘처럼 정답을 아는 모의실험에서 쌓은 적중률입니다. 보고서에는 표본 설계(비복원·무작위 여부)와 모집단 크기를 함께 적습니다.

비유의 한계: 모의실험의 모집단이 실제 상황과 다르면 적중률도 달라집니다.
