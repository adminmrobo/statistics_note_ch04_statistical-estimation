왜 이 실습인가

1변수가 많은 실제 모양의 데이터

지금까지는 변수 하나였습니다. 15개 변수 1,000명 데이터에서 무엇부터 보고, 어떤 구간을 만들지 순서를 익힙니다.

2집단 비교

"남녀 혈압이 다른가?"처럼 두 집단을 비교할 때 구간 두 개를 겹쳐 보는 대신 차이의 구간을 만듭니다.

3기준값과 비율

고혈압·고혈당 기준으로 나눈 비율에도 구간이 필요합니다. 평균과 비율 두 가지 구간을 한 데이터에서 모두 씁니다.

박사

박사의 한 줄: 큰 데이터일수록 순서가 중요해요. 프로필 → 변수별 구간 → 집단 비교 → 기준값 비율.

데이터에 대해: 실습 파일 simulated_patient_data.csv는 이름 그대로 모의(가상) 환자 데이터입니다. 이 페이지에는 그 파일(1,000행)을 그대로 넣어 계산합니다. 원본 그대로라 간효소 수치가 음수인 행(2개)이나 BMI가 12 미만인 행(10개)처럼 실제로는 나오기 어려운 값도 섞여 있습니다 — ①칸에서 프로필을 먼저 보는 이유입니다. 다른 파일로 해 보려면 아래 "내 CSV 열기"를 쓰세요. 가상 데이터이므로 실제 환자 집단에 대한 의학적 결론이 아닙니다.

1프로필

데이터 프로필 — 숫자를 보기 전에 데이터를 본다

모델: 변수 유형·단위·범위·요약검진센터: 1,000명 검사표

검진센터에서는

1,000명의 검사표에는 15개 항목이 있습니다. 단위(mg/dL), 범위(18~90세), 성별 같은 범주 변수를 먼저 확인하지 않으면 평균을 내도 엉뚱한 숫자가 나옵니다.

통계로는

데이터 프로필: 변수 이름·유형·단위·결측·범위·평균·표준편차·분포 모양. 치우친 변수(중성지방, 간수치)는 평균과 중앙값이 벌어집니다.

2구간

변수별 95% 신뢰구간 — 한 표에

모델: x̄ ± t(n−1)·s/√n검진센터: 연간 보고서 표

검진센터에서는

연간 보고서에는 항목마다 "평균 (95% 신뢰구간)"을 한 줄씩 적습니다. n = 1,000이면 구간이 좁아 평균을 꽤 정확히 압니다.

통계로는

변수마다 t 구간을 만듭니다(대표본이라 z와 거의 같음). 다만 구간을 13개 동시에 보면 하나쯤은 우연히 빗나갈 수 있습니다(다중 비교).

파이썬 한 번에 만들기 
import pandas as pd, numpy as np
from scipy import stats
df = pd.read_csv('simulated_patient_data.csv')
num = df.select_dtypes('number').drop(columns='id')
n = len(num); tc = stats.t.ppf(0.975, n - 1)
out = pd.DataFrame({'mean': num.mean(), 'sd': num.std()})
out['lo'] = out['mean'] - tc * out['sd'] / np.sqrt(n)
out['hi'] = out['mean'] + tc * out['sd'] / np.sqrt(n)
print(out.round(2))
3비교

남녀 비교 — 겹침이 아니라 차이의 구간

모델: (x̄₁ − x̄₂) ± t·√(s₁²/n₁ + s₂²/n₂)검진센터: 성별 보고서

검진센터에서는

"남자와 여자의 평균 혈압이 다른가?" 막대 그래프에 오차 막대 두 개를 그려 겹치는지 보는 경우가 많습니다. 그런데 겹친다고 차이가 없는 것은 아닙니다.

통계로는

두 평균의 차이 자체에 구간을 만듭니다. 분산이 다를 수 있으니 Welch 방법을 씁니다. 0을 포함하지 않으면 이 자료로 차이가 있다고 말할 수 있습니다. 단, 차이의 원인(성별인지 나이인지)은 교란 때문에 이 계산만으로 말할 수 없습니다.

여자 쪽이 평균 나이가 다르면? 혈압 차이가 성별 탓인지 나이 탓인지 어떻게 알아?

4기준값

임상 기준값으로 나눈 비율의 구간

모델: p̂ ± 1.96·√(p̂(1−p̂)/n)검진센터: 유소견자 비율

검진센터에서는

수축기 혈압 140 이상(고혈압 범위), 공복 혈당 126 이상(당뇨 범위)인 사람의 비율을 보고합니다. 이 비율도 표본에서 나온 추정값입니다.

통계로는

기준을 넘은 사람의 표본비율에 2.2의 비율 구간을 씁니다. 비율이 작으면(몇 %) 구간이 상대적으로 넓습니다.

기준

읽을 때 주의

  • 기준값은 진단 기준의 일부일 뿐이며, 한 번 측정한 값만으로 진단하지 않습니다. 여기 비율은 "기준을 넘은 측정의 비율"입니다.
  • 모의 데이터의 비율은 실제 인구의 유병률이 아닙니다.

현장에 옮기면

실제 검진 데이터는 결측, 단위 혼용, 같은 사람의 반복 측정이 섞입니다. 구간을 만들기 전에 한 사람당 한 행인지, 측정 시점이 같은지 확인합니다.

비유의 한계: 의료 데이터는 개인정보이므로 분석 환경과 반출 규칙을 지켜야 합니다.
